# Analizador Ejecutivo Local

Aplicación de escritorio para Windows que permite cargar, explorar, filtrar, deduplicar, comparar y visualizar archivos CSV, XLSX, JSON y XML. El procesamiento de los datos se realiza localmente en la computadora.

## Descargar

[Descargar Analizador Ejecutivo Local 0.3.1 para Windows](https://github.com/AgusPalombo/ETL-APP-CV/releases/download/v0.3.1/Analizador-Ejecutivo-Local-Setup-0.3.1.exe)

## Privacidad

Los archivos cargados, filtros, resultados y datos de uso no se envían a GitHub ni a servicios externos. La conexión a GitHub se utiliza únicamente para consultar y descargar versiones nuevas cuando el usuario habilita o solicita una actualización.

## Actualizaciones

La aplicación puede comprobar si existe una versión nueva desde el icono de la bandeja de Windows. Cada descarga se verifica localmente mediante SHA-256 antes de ejecutar el instalador y siempre requiere confirmación del usuario.

Este repositorio es exclusivamente el canal de descarga y actualización. Solo contiene esta presentación y los archivos binarios necesarios para instalar o actualizar la aplicación.
